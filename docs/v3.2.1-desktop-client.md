# TarsSecureGuard v3.2.1 桌面客户端设计与实施说明

> 定位：**本地 Tauri 客户端，不依赖浏览器**。双击安装 → 原生窗口打开中文管理台 → 关窗即收。
> 本文是 `src-tauri/` 桌面壳与网关侧最小适配的设计决策、模块拆分、构建与验收的唯一权威出处。

---

## 一、目标与边界

| 项 | 内容 |
|---|---|
| 要解决的 | "解压双击后依赖系统浏览器打开 `http://127.0.0.1:18889`"——浏览器被安全策略禁用 / 被占用 / 用户不想要浏览器时体验断裂 |
| 交付形态 | 叠加的第四种交付形态：CLI 单文件（不变）、systemd（不变）、Docker（不变）、**桌面安装包（新增）** |
| 硬性约束 | ① 零浏览器依赖（系统自带 WebView 可接受）② CLI/systemd/Docker 行为零变化 ③ 安全链（WAF/RBAC/审计/鉴权）一行不削 |
| 不做 | WS 事件流、单实例锁、updater、托盘、keychain、开机自启（均留 v3.2.2+，防范围蔓延） |

## 三、模块拆分

| 模块 | 文件 | 职责 |
|---|---|---|
| Rust 壳 | `src-tauri/src/lib.rs` | 生命周期编排：探活 → 连接模式/spawn → 就绪轮询 → 退出清理 |
| Rust 入口 | `src-tauri/src/main.rs` | `windows_subsystem` 静默控制台 + 调 `run()` |
| 打包配置 | `src-tauri/tauri.conf.json` | 窗口（先隐藏就绪后显示）、externalBin sidecar、CSP null（本地资产、无远程加载）、NSIS currentUser、WebView2 embedBootstrapper |
| 权限 | `src-tauri/capabilities/default.json` | 前端无 IPC 调用，权限集为空（最小权限）；sidecar 由 Rust 侧拉起 |
| 图标 | `src-tauri/icons/app-icon.png` | 单一源图，CI `tauri icon` 生成全套平台图标 |
| Go 网关 | `main.go` `config.go` | `--no-browser` 标记、`TSG_APP_DIR` override、`isTrustedOrigin` 信任 Tauri origin、版本号 3.2.1 |
| 前端 | `frontend/index.html` | `api()` 增加 API BASE（桌面模式生效）、桌面启动遮罩、侧边栏版本标签 |
| CI | `.github/workflows/desktop-release.yml` | 三平台 matrix：Go sidecar 编译（mac lipo universal）→ `tauri icon` → `tauri build` → artifacts/Release |

## 四、关键技术决策

1. **Tauri 2.12（非 v1）**：v1 停在 1.5.x 已死线；2.12 为 2.x 当前稳定（MSRV Rust 1.90，弃 Win7——与 Go 侧 Windows 10+ 基线一致）。遇阻降 2.11.5 只改 `Cargo.toml` 一行。
2. **"不依赖浏览器"实现**：Tauri 用系统自带 WebView（Win=WebView2 引导安装、mac=WKWebView 系统_builtin、Linux=webkit2gtk 4.1 deb 依赖），不捆绑 Chromium、不用用户浏览器。
3. **Sidecar 外嵌（非重写）**：Go 网关整体作为 sidecar 二进制打进安装包，按 target-triple 命名由壳 spawn；**不把 Go 逻辑重写为 Rust、不进程内嵌**——保留零依赖单文件网关的全部工程特性。
4. **通信不新增协议**：UI→Go 仍走既有 REST + `X-API-Key`（鉴权链原样）；Rust→Go 仅免鉴权 `/health` 探活 + 进程信号。
5. **前端跨源方案**：前端资产由 Tauri 服务（`tauri://localhost`），`api()` 跨源 fetch 由 Go `isTrustedOrigin` 信任 + CORS 放行——20+ 处 API 调用收敛于唯一 `api()` 函数，单点改造。
6. **数据目录 `TSG_APP_DIR`**：桌面安装位置不可写（Program Files / /usr/bin / AppImage 只读 squashfs），壳把网关数据目录指到系统用户数据目录；CLI/systemd/Docker 不设此变量，行为零变化。
7. **杀进程语义**：正常关窗 → `RunEvent::Exit` → kill sidecar（连接模式不杀外部实例）。壳被强杀时 sidecar 可能残留为**已知限制**（Job Object 兜底留 v3.2.2）。

## 五、构建

```sh
# 1) Go 网关 sidecar（仓库根目录）
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags "-s -w" \
  -o src-tauri/binaries/tsg-x86_64-unknown-linux-gnu .
#   macOS universal：amd64+arm64 各编译一份后 lipo 合并为 tsg-universal-apple-darwin
#   Windows：tsg-x86_64-pc-windows-msvc.exe

# 2) 图标（一次性；CI 每次自动执行）
npx tauri icon src-tauri/icons/app-icon.png     # 需 @tauri-apps/cli@^2

# 3) 壳
npx tauri build --target x86_64-unknown-linux-gnu --bundles deb,appimage
# Linux 需先安装：libwebkit2gtk-4.1-dev libgtk-3-dev libayatana-appindicator3-dev librsvg2-dev patchelf
```

CI（`desktop-release.yml`）已封装全流程；MSRV Rust 1.90、Go 1.22.5+、Node 20+。

## 七、已知限制（如实声明）

- 壳被强杀（任务管理器杀 TSG.exe）时 sidecar 可能残留——正常关窗不触发；Job Object 兜底留 v3.2.2。
- 连接探测固定 18889 默认端口：CLI 用 `-port` 自定义端口的实例不被桌面版复用（会另起默认端口实例）。
- Rust 侧代码未经本沙箱编译（环境所限），首次 CI 运行为编译验证关口。
