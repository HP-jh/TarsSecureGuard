# TarsSecureGuard v3.5.0 极致模块化与自适应

对应 11 项纵深路线图中的：**项 6（极致模块化：非核心全可选化、按需裁剪）+ 项 7（自适应适配：设备性能 / 使用习惯 / 新手-高阶模式）**。

## 一、裁剪档案（项 6：按需裁剪）

- **内置档案 5 套**，一键切换整套模块组合（应用时依赖自动补全、落审计、工作者立即对齐）：
  - `minimal` 极简：仅安全核心 + 对话链路（chatApi / localModels / cloudModels / memory / builtinTools / stats）
  - `standard` 标准：按注册表默认拓扑展开（跟随版本演进，不硬编码）
  - `full` 全量：默认关闭的也全开（customTools / customAgents / autoStartModel / urgentChat）
  - `privacy` 纯本地：零外联——关闭云端模型 / 搜索 / 抓取 / MCP / 连接器 / 外置宿主等一切对外网络模块
  - `lowspec` 低配：D 档设备省资源档，保留资源守护器与语义分级（省资源不降安全）
- **依赖闭合（档案语义）**：显式开启集为唯一权威——BFS 传递闭包补全依赖（连带开启并落审计），未被任何开启模块需要的模块一律关闭；结果与处理顺序无关（配置热重载路径的迭代式纠正保持不变，两套语义各司其职）
- **自定义档案**：把当前模块开关组合保存为命名档案（`config` 顶层 `moduleProfiles` 段，名称限字母数字-_/1~32 字符），随时套用 / 删除；不能覆盖内置档案名
- **dry-run**：`POST /api/admin/v35/profile {action:"apply", profile, dryRun:true}` 只返回变更清单（from→to）不实际应用
- **API**：`GET/POST /api/admin/v35/profile`（清单 + 当前态 + UI 模式 + 模块使用统计 / apply / save / delete）

## 二、自适应建议引擎（项 7：设备性能 + 使用习惯）

- **模块使用埋点**：`moduleRoute` 每次命中记账（调用次数 + 最后使用时间，进程内、重启清零）；关闭态不埋点
- **建议规则**（GET `/api/admin/v35/adaptive`，纯函数式生成；POST `{apply: id}` 一键应用并落审计 `ADAPTIVE_APPLY`）：
  - R1 eco：硬件 D 档 + eco 未启用 → 建议 eco 省资源档
  - R2 裁剪：开启但自启动以来从未调用、且无开启中依赖方的 tools/ops 类模块 → 建议关闭省资源、缩小攻击面（core/models/security 类不自动建议）
  - R3 增强：硬件 S/A/B 档 + 有本地模型 + autoStartModel 关 → 建议开启启动自拉
  - R4 提示：Token 累计成本 > $1 且本地模型可用 → 本地优先降本提示（纯信息不自动改）
- **成本数据源**：Token 测量器按天聚合（`meterTotalCost`），与 v3.4.0 计量口径一致

## 三、新手 / 高阶界面模式（项 7：使用门槛自适应）

- `config` 顶层 `ui.mode`：`advanced`（默认）/ `beginner`；`GET/POST /api/admin/v35/ui-mode` 切换，落审计 `UI_MODE_CHANGE`
- 新手模式前端只保留核心页面（仪表盘 / 对话 / 模型 / 智能体 / 设置 / 关于），隐藏模块、治理、连接器等 18 个高级导航项；启动时自动拉取模式并应用，切回高阶即时恢复
- 模块管理页（高阶）内置模式开关 + 裁剪档案卡片（含「当前」态与模块数徽标）+ 自适应建议列表 + 档案保存/删除

## 四、模块化

- 新增 `adaptive` 模块（ops 类，默认开启，无依赖）：档案 / 建议 / UI 模式三组路由随模块开关热生效（关停 503）

## 五、验证

- `go build` / `go vet` 干净；`go test -race -count=1 ./...` 全绿
- v3.5.0 专项测试（v350_test.go，8 用例）：moduleRoute 使用埋点（开态计数 / 关态不计数）/ 内置档案合法性（minimal 核心链路、privacy 零外联、lowspec 保安全不降级）/ 档案依赖闭合（传递补全、不复活显式关闭、顺序无关性）/ dryRun 变更清单与不实际应用 / 自定义档案生命周期（名称清洗、覆盖保护、取回）/ 建议引擎（结构、目标模块校验、未知建议报错）/ UI 模式（默认值、非法值回退）/ API handler（400/404/200 路径）/ adaptive 模块注册
- 版本锁测试更新至 3.5.0
