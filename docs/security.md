# TarsSecureGuard 安全模型

## 1. 纵深防御体系

```
┌─────────────────────────────────────────┐
│  L1: WAF (Web Application Firewall)     │
│  - SQL 注入 / XSS / 命令注入检测         │
│  - 速率限制 (120 req/10s per IP)        │
│  - IP 信誉表 (动态封禁)                  │
├─────────────────────────────────────────┤
│  L2: 身份认证                            │
│  - API Key (Bearer Token)               │
│  - 默认密钥启动警告                       │
├─────────────────────────────────────────┤
│  L3: RBAC (基于角色的访问控制)            │
│  - global_admin / admin / user          │
│  - 模块级权限矩阵                         │
├─────────────────────────────────────────┤
│  L4: 审计与日志                          │
│  - 全量请求审计日志                       │
│  - Hash Chain 防篡改                      │
│  - 分级日志 (INFO/WARN/ERROR/WAF)        │
├─────────────────────────────────────────┤
│  L5: 文件安全边界                         │
│  - allowedRoots 白名单                   │
│  - 路径规范化 (EvalSymlinks)             │
│  - 禁止符号链接逃逸                       │
├─────────────────────────────────────────┤
│  L6: 进程自我保护                         │
│  - 内存软上限                             │
│  - 自保护信号处理                         │
│  - 防内存转储 (极致档)                    │
└─────────────────────────────────────────┘
```

## 2. WAF 规则

### 检测类型

| 类型 | 触发条件 | 动作 |
|------|----------|------|
| SQL 注入 | `UNION SELECT`, `OR 1=1` | 拦截 + 记 WAF 日志 |
| XSS | `<script`, `javascript:` | 拦截 |
| 命令注入 | `;`, `|`, `` ` `` | 拦截 |
| 路径遍历 | `../`, `..\` | 拦截 |
| 敏感词 | 系统提示词泄露尝试 | 拦截 |

### 性能优化

- 合并正则 + ASCII 预筛选：strict 中文场景 474µs → 0.99µs
- 响应缓存：16 分片锁，-10% 延迟

## 3. RBAC 矩阵

| 端点前缀 | global_admin | admin | user |
|----------|-------------|-------|------|
| `/api/admin/*` | 全部 | read/write 类 | 无 |
| `/api/chat/*` | 全部 | 全部 | 全部 |
| `/api/search` | 全部 | 全部 | 需模块开启 |
| `/api/kb/*` | 全部 | 全部 | query |
| `/metrics` | 全部 | 全部 | 全部 |

## 4. 审计链

审计日志结构：
```json
{
  "timestamp": "2026-10-17T21:00:00Z",
  "method": "POST",
  "path": "/api/chat/completions",
  "ip": "127.0.0.1",
  "role": "user",
  "status": 200,
  "duration_ms": 45,
  "hash": "sha256-of-previous-log"
}
```

Hash Chain 确保日志不可篡改。

## 5. 极致档安全

v4.17.x 极致档额外启用：

- **分层加密**: 配置文件 AES-256-GCM
- **启动验证哨兵**: 关键代码段哈希校验
- **透明加密**: 内存中敏感数据自动加密
- **防内存转储**: 阻止 ptrace / 核心转储
- **2FA 升级确认**: 自动更新需二次确认
