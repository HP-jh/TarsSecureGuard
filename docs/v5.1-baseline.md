## 4. 与 spec 历史值对比

| 指标 | spec 历史 | 本次实测 | 差异说明 |
|------|-----------|----------|----------|
| WAF 常规 | 71,301 ns/op | 70,849 ns/op | ~0.6% 差异，硬件不同 |
| WAF strict | 480,310 ns/op | 448,315 ns/op | ~6.7% 差异，硬件不同 |
| PII 脱敏 ns/op | 178,025 | 196,842 | ~10.6%，硬件不同 |

**结论：** spec 中的历史数据基本可复现。后续所有性能优化对比以本文件中的实测数据为基线，不引用历史百分比。
