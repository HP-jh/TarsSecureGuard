   ```go
   type Pipeline struct {
       stages []Stage

   }

   ```

2. **Observer 可观测性接口** (`internal/pipeline/observer.go`)
   ```go
   type Observer interface {
       OnStageStart(name string, rc *RequestContext)
       OnStageEnd(name string, rc *RequestContext, result StageResult, duration time.Duration, err error)
       OnPipelineComplete(rc *RequestContext, halted bool, totalDuration time.Duration)
   }
   ```

3. **Shadow Bridge 桥接器** (`internal/pipeline/shadow.go`)
   ```go
   type BridgeMode int

       ModeGradual                     // 渐进模式：Pipeline 优先，legacy 兜底

   )
   ```
