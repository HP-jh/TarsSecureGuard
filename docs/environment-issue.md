# 环境问题登记

## P2: 本机 Go 程序大响应写 socket 卡 4KB

**登记时间**: 2026-10-11
**等级**: P2（环境级，非代码 bug）
**影响范围**: 单台开发机

### 现象

- 任何 Go 版本（已测 1.22.8 / 1.24.4）编译的 HTTP 服务器在本机写 >4KB socket 响应即挂起
- 卡在 4KB 边界，8s 超时，响应被截断
- 对照实验：同机同场景 Node.js 服务器 166KB 响应 11ms 正常

### 影响

- 浏览器直接访问本机 127.0.0.1:18889 超时
- TSG 前端无法通过服务加载（需用 file:// 直开绕过后端验证）

### 排查方向

- **首要嫌疑**: 火绒 HipsDaemon（HIPS 进程在运行）对 Go 程序网络行为做分析/限制
- 建议检查火绒「联网控制 / 信任区 / 网络防护」规则，将 tsg 加入信任区
- 若无法定位，在另一台干净机器上复现验证，确认是否为本机环境特有

### 结论

- 非 TSG 代码回归，勿在代码层面反复排查
- 后续若复现或解决，请更新本文档
