## 一、统一安装器（小白化部署）

### install.sh（Linux / macOS）
- 自动识别：`uname -s` → linux / darwin（Windows Git Bash/MSYS 环境会引导改用 install.ps1）
- 自动架构：`uname -m` → x86_64/amd64 → amd64，aarch64/arm64 → arm64
- 下载源：默认 GitHub Releases `tsg-{os}-{arch}`（latest 或 `TSG_VERSION` 指定 tag）；`TSG_BASE_URL` 可覆盖为镜像或本地目录（file 协议外的本地路径直接 cp，离线可装）
- 安装位置：默认 `~/.tsg/bin/tsg`，`TSG_INSTALL_DIR` 可覆盖
- PATH：小白化默认自动写入 shell 配置（幂等、带 `# TarsSecureGuard PATH` 标记）；`TSG_NO_PATH_MOD=1` 关闭
- 卸载：删除安装目录即净

一键命令：
```sh
curl -fsSL https://raw.githubusercontent.com/HP-jh/TarsSecureGuard/main/install.sh | sh
```

### install.ps1（Windows）
- `PROCESSOR_ARCHITECTURE` → AMD64/ARM64 → amd64/arm64，资产 `tsg-windows-{arch}.exe`
- 安装到 `%LOCALAPPDATA%\TarsSecureGuard`，幂等写入用户 PATH
- 支持 `-Version` / `-BaseUrl` / `-InstallDir` 参数；`file://` 与本地路径支持离线安装统一安装包场景

一键命令：
```powershell
irm https://raw.githubusercontent.com/HP-jh/TarsSecureGuard/main/install.ps1 | iex
```

### 统一安装包 tsg-setup.zip
打包 install.sh + install.ps1 + 快速开始卡片：小白用户下载**一个文件**，任意系统双击/运行对应安装器即可，无需知道自己的 OS 版本与 CPU 架构。

## 二、官方引流站（site/）

- `site/index.html`：轻量单页官网（单文件、内联 CSS、无外部依赖，GitHub Pages 即托管即用）
  - 内容：核心特性 8 卡（安全网关 / 转换中枢 / 模型库 / 连接器 / 模块化 / 自适应 / Token 测量器 / 解压即用）、一键安装命令、版本里程碑、FAQ、GitHub 入口（仓库 / Releases / Issues）
  - SEO 基线：`title` + `meta description` + `meta keywords`、`canonical`、Open Graph、Twitter Card、JSON-LD `SoftwareApplication` 结构化数据、语义化 HTML、`lang="zh-CN"`
- `site/robots.txt`：全量 Allow + Sitemap 声明
- `site/sitemap.xml`：站点地图（GitHub Pages 域名）
- 启用方式：仓库 Settings → Pages → Deploy from branch → main 分支 /site 目录（无需 CI）
