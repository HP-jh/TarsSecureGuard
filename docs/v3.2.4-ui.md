# TarsSecureGuard v3.2.4 UI 升级报告

> 路线图定位：v3.2.4 = UI 升级（管理台前端界面与交互）。
> 核心事实：v3.2.2 治理层交付了 8 个 REST 端点（共享记忆/共享信息/上下文包/守门人/OAuth/审计 v2 校验导出/治理总览），
> 但管理台前端（`frontend/index.html`，embed.FS 单文件）**零覆盖**——治理能力只能靠 curl 触达。
> 本轮把这层能力全部可视化，同时修复侧边栏版本徽章自 v3.2.1 起未随版本更新的漂移。

## 一、新增「治理」导航组（4 页面，16 导航项 → 21）

### 1. 治理总览（Governance）
`GET /api/admin/v322/status` + `GET /api/admin/oauth/status`：
- 统计卡×4：共享记忆命名空间（含 keys 与每 ns 上限）、共享信息条目、上下文包、OAuth 会话；
- 守门人卡片：enforce/observe 模式、待确认操作数、自定义规则数、**内置不可放宽规则逐条列出**；
- OAuth/OIDC 卡片：enabled/ready、issuer、clientId、活跃会话与 TTL、roleClaim 与映射条数（不泄密）；
- 审计 v2 卡片：格式、保留天数、可用日期。

### 2. 共享记忆（Shared Memory）
`GET/POST/DELETE /api/context/memory`：
- 写入表单（key / value / namespace / TTL 秒），写入后列表自动刷新并 toast 回报 revision；
- 三层解析链合并视图表格（key / namespace 层 / value 预览 / 更新时间与人 / 删除），支持 key 前缀过滤。

### 3. 共享信息（Shared Info）
`GET/POST/DELETE /api/context/info`：
- 新增表单（type / 标题 / scope / 置信度 / 标签 / 内容）；
- 条目卡片列表：type 徽标、scope、置信度、revision、更新时间、标签、内容全文，支持关键词搜索 + 类型过滤（服务端加权检索：标题 100 > 标签 80 > 内容 40）。

### 4. 审计链 v2（Audit Chain）
`GET /api/admin/audit/verify` + `GET /api/admin/audit/export`：
- 日期下拉（来自 `availableDates`）→ **重算全链**：链完整显示绿色「N 行全链重算一致」；断裂显示红色断点行号与问题描述；
- **导出 JSONL**：fetch 带 `X-API-Key` 头取 blob 下载（租户行级过滤由服务端执行）。

## 二、交互与一致性修复

- 侧边栏版本徽章 `v3.2.1 DESKTOP` → `v3.2.4`（该静态字符串自 v3.2.2 起漏更，About 页为动态读 API 无此问题）；
- 新页输入控件统一复用既有 `.input` / `.btn` / `.tag` / `.stat` 设计系统，零新增 CSS 依赖、零外部资源；
- 新页面全部纳入 hash 路由（`#gov` / `#memory` / `#sinfo` / `#audit2` 可直达）与 pg() 懒加载链。

> 修复的开发中缺陷：内容输入框与列表容器 ID 冲突（`si-content` 重名导致列表渲染写入 input 元素）——已改名 `si-body` 并全页 ID 唯一性核查通过。

## 四、安全不妥协声明

- 前端零特权：所有操作走既有 REST，鉴权（X-API-Key / Bearer）与 RBAC / 租户过滤全部由服务端执行；
- 审计链校验仍要求 global_admin / global_auditor 视野，导出仍按租户行级过滤并落审计事件——UI 只是调用方，未放松任何一道闸；
- 导出下载不落 URL（密钥走请求头，不进地址栏 / 历史记录）。
