常见问题

安装、升级、迁移、兼容性、安全——你关心的问题，这里都有答案

支持哪些操作系统？
Windows、macOS、Linux、Android 的 amd64 / arm64 架构；安装器自动识别。
需要安装运行环境吗？
不需要。TSG 是单文件原生二进制，无容器、无数据库、无运行时依赖。
支持本地大模型吗？
支持。自动发现 Ollama / LM Studio / llama.cpp 等本地推理服务，Token 测量器实时对比云端成本。
数据会上传吗？
不会。默认零外联可裁剪，「纯本地」档案一键关闭全部对外网络模块，审计与密钥均在本机。
如何卸载？
删除安装目录（默认 ~/.tsg/bin 或 %LOCALAPPDATA%\TarsSecureGuard）即可，不残留系统组件。
如何升级？
订阅版支持一键更新包；社区版下载新版二进制覆盖即可，config.json 与数据自动保留。
从 LiteLLM / 其他网关迁移难吗？
简单。TSG 暴露标准 OpenAI 兼容端点，把 base_url 和 api_key 指向 TSG 即可，客户端零改动。
安全策略可以放宽吗？
不能。Security Core 强制加载且不可关闭，「AI 只能加严」单向合并铁律，100% 单测 + 运行时审计锁定。
企业 IdP 怎么接？
配置 OAuth/OIDC Authorization Code + PKCE，支持 RS256/ES256 验签，角色映射自动校验进 RBAC 矩阵。
性能瓶颈在哪？
v3.2.3 起 WAF 合并正则 + 字节预筛已解决主要瓶颈（strict -99.8%）；连接池复用率 98.5%，P99 -27%~-40%。
API Key 怎么管理？
默认密钥启动时随机生成，建议通过 TSG_ADMIN_KEY 环境变量注入；管理端操作全程审计。
为什么叫「路由器」？
路由器不生产网线，也不生产网站——它让每一台设备安全上网。TSG 不生产模型，它让每个 AI 客户端安全地用上每个模型。
