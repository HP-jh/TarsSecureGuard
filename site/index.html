FAQ

常见问题

支持哪些操作系统？
Windows、macOS、Linux、Android 的 amd64 / arm64；安装器自动识别。
需要安装运行环境吗？
不需要。TSG 是单文件原生二进制，go.mod 零第三方依赖，无容器、无数据库。
支持本地大模型吗？
支持。自动发现 Ollama / LM Studio / vLLM，配合 Token 测量器做云端/本地成本对比。
和 LiteLLM 有什么区别？
LiteLLM 是 Python 栈，需要 Postgres+Redis，镜像近 1GB。TSG 是零依赖单文件，Security Core 强制开启，--mcp-stdio 即插即护，服务于"今天就想安全地把本地 AI 用起来"的个人与隔离内网。

准备好给 AI 系好安全带？
