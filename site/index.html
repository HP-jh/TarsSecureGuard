FAQ

常见问题

支持哪些操作系统？

Windows、macOS、Linux 的 amd64 / arm64 架构，外加 Android（arm64）；安装器自动识别，无需手动选版本。前往下载页。

需要安装运行环境吗？

不需要。TSG 是单文件原生二进制，无容器、无数据库、无运行时依赖，解压或安装后直接运行。

支持本地大模型吗？

支持。自动发现本地推理服务（Ollama 等 8 种运行时），配合 Token 测量器可实现云端 / 本地成本对比与本地优先。

数据会上传吗？

不会。网关默认零外联可裁剪（「纯本地」档案一键关闭全部对外网络模块），审计与密钥均在本机。

和 LiteLLM / One API 有什么区别？

核心差异是「默认值」：TSG 把安全（WAF / PII / 审计）、工具一键配置（Extender）、纯本地模式做成了开箱即用的默认能力，且是零依赖单文件部署。详见上方对比表。

如何卸载？

删除安装目录（默认 ~/.tsg/bin 或 %LOCALAPPDATA%\TarsSecureGuard）即可，不残留系统组件。
