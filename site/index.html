02快速开始 · 一键安装

macOS / Linux（自动识别系统与 CPU 架构）：

curl -fsSL https://raw.githubusercontent.com/HP-jh/TarsSecureGuard/main/install.sh | sh

Windows PowerShell：

irm https://raw.githubusercontent.com/HP-jh/TarsSecureGuard/main/install.ps1 | iex

安装后启动（首次运行自动生成配置与随机密钥）：

tsg          # 启动网关，面板自动打开 http://127.0.0.1:18889
tsg doctor   # 环境自检

也可以从 GitHub Releases 手动下载对应平台二进制，或下载统一安装包 tsg-setup.zip（含全平台安装器，运行后自动识别系统）。

04常见问题

支持哪些操作系统？
Windows、macOS、Linux 的 amd64 / arm64 架构；安装器自动识别，无需手动选版本。
需要安装运行环境吗？
不需要。TSG 是单文件原生二进制，无容器、无数据库、无运行时依赖，解压或安装后直接运行。
支持本地大模型吗？
支持。自动发现本地推理服务（Ollama 等），配合 Token 测量器可实现云端 / 本地成本对比与本地优先。
数据会上传吗？
不会。网关默认零外联可裁剪（「纯本地」档案一键关闭全部对外网络模块），审计与密钥均在本机。
如何卸载？
删除安装目录（默认 ~/.tsg/bin 或 %LOCALAPPDATA%\TarsSecureGuard）即可，不残留系统组件。
