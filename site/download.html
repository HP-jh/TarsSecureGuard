03下载后如何校验（推荐）

确认下载没有损坏或被篡改。先下载 SHA256SUMS.txt，与二进制放同一目录：

# macOS / Linux
shasum -a 256 -c --ignore-missing SHA256SUMS.txt

# Windows (PowerShell)
Get-FileHash .\tsg-v*-windows-amd64.exe -Algorithm SHA256

输出的哈希值与 SHA256SUMS.txt 里对应行一致，就说明文件完好。

04快捷方式与启动

安装器会自动做什么

  • Linux：创建桌面快捷方式（.desktop）并写入开始菜单
  • Windows：创建桌面快捷方式 + 开始菜单快捷方式（.lnk）
  • macOS：把命令行入口装到 ~/.tsg/bin，并生成可双击的「TSG 控制台」命令

双击快捷方式会发生什么

快捷方式启动本地网关，面板自动打开；已安装桌面客户端（v4.6.0+）时会优先调起客户端窗口，而不是浏览器标签页。重复点击不会启动第二个实例。

桌面客户端（可选进阶）

想要像 VS Code 一样的独立窗口体验？从源码构建 Tauri 桌面壳（src-tauri/），支持 tsg:// 协议调起、单实例锁与系统托盘。
